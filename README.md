# 📊 Bharti Airtel Financial Valuation Model

A comprehensive Financial Valuation Model of Bharti Airtel Limited developed in Microsoft Excel.

## 📌 Project Overview

This project includes a detailed financial analysis and valuation of Bharti Airtel using industry-standard valuation techniques.

## 🔍 Key Highlights

- Historical Financial Statement Analysis
- Revenue & Expense Forecasting
- DCF (Discounted Cash Flow) Valuation
- FCFF Valuation
- WACC Calculation
- Terminal Value Estimation
- Sensitivity Analysis
- Investment Recommendation

## 🛠️ Tools Used

- Microsoft Excel
- Financial Modeling
- DCF Valuation
- Ratio Analysis
- Annual Reports
- Screener & Yahoo Finance Data

## 📁 Repository Contents

- Airtel Valuation Model.xlsx
- Financial Analysis
- Valuation Assumptions
- Forecast Model

## 🎯 Objective

To estimate the intrinsic value of Bharti Airtel and evaluate whether the stock is undervalued or overvalued using professional financial modeling techniques.
