# 📊 Bharti Airtel Financial Valuation Model

> A comprehensive Financial Modeling & Equity Valuation project developed using Microsoft Excel to estimate the intrinsic value of Bharti Airtel Limited through industry-standard valuation methodologies.

---

## 📌 Project Overview

This project presents a complete financial valuation of **Bharti Airtel Limited**, one of India's largest telecommunications companies. The valuation model has been built from scratch using historical financial statements, forecast assumptions, and Discounted Cash Flow (DCF) methodology.

The model demonstrates practical financial modeling techniques used by Equity Research Analysts, Investment Banking Analysts, Corporate Finance professionals, and FP&A teams.

---

## 🎯 Project Objectives

- Analyze the historical financial performance of Bharti Airtel.
- Forecast future financial statements using realistic business assumptions.
- Calculate Enterprise Value and Equity Value using DCF methodology.
- Estimate the Intrinsic Share Price.
- Perform Sensitivity Analysis under different assumptions.
- Provide an investment recommendation based on valuation results.
